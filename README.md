## Quick facts

- Buy-in: **1 HILO** ($20 peg) · **20%** treasury / **80%** vaulted  
- Play: Higher / Lower · **20 HP** · **±3** · **20s** clock  
- Extract: **3 HP = 0.1 HILO**  
- Shoe: HMAC-SHA256 commitment (client)
